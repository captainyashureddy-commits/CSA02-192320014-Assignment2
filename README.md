# SIMATS — C Programming Assignment 2

## Project Title
Designing, Implementing and Validating a Reliable Billing Program for a Rural Electricity Co-operative

## Introduction
This assignment demonstrates essential C programming concepts through the development of an electricity billing system.

The project covers header files, conditional compilation, input validation, formatted output, type conversion, integer arithmetic, GCC compilation stages and smart-meter billing.

## Assignment Tasks

### Task01 — Header Files and Conditional Compilation
- Implemented `billing.h` and `main.c`.
- Used include guards and conditional compilation.
- Demonstrated normal and DEBUG modes.
- Sample bill: Rs. 500.00.

### Task02 — Input Validation and Formatted Output
- Implemented user input using `scanf()`.
- Validated negative and non-numeric inputs.
- Displayed bills in rupees and paise.
- Sample bill: Rs. 500.00.

### Task03 — Type Conversion and Rounding
- Demonstrated integer and floating-point division.
- Used explicit type conversion and rounding.
- Compared monetary calculations.
- Sample calculation: Rs. 393.75.

### Task04 — GCC Compilation Stages
- Documented preprocessing, compilation, assembly and linking.
- Explained common C programming errors.
- Implemented a sample billing program.
- GCC stage-by-stage execution evidence is pending.

### Design Challenge — Smart Meter Billing
- Designed a 15-minute interval billing prototype.
- Used time-of-day tariff rates.
- Calculated electricity consumption and charges.
- Sample final bill: Rs. 57.30.
